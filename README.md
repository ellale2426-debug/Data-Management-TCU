# Data-Management-TCU
A collection of coursework and hands-on exercises for INSC 30823: Data Management, using the AdventureWorks relational database.
Database: AdventureWorks
DBMS: PostgreSQL (if applicable)
Data domain: Employee records, departments, employment history, and contact information.
SQL Skills Practiced:
Data Retrieval & Filtering: SELECT, WHERE, DISTINCT, ORDER BY
Relational Joins: INNER JOIN, LEFT JOIN, table relationships, and join conditions
Set Operations: UNION, UNION ALL, INTERSECT, EXCEPT
NULL Handling: identifying missing phone information and applying IS NULL / IS NOT NULL
Business Rules: identifying current employees using employment history and EndDate IS NULL
Data Quality & Validation: understanding duplicate rows, join multiplicity, and result verification
